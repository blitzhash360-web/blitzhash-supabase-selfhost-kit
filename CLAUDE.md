Install the skill for use in other projects:

```bash
mkdir -p ~/.claude/skills
cp -R skills/supabase-selfhost ~/.claude/skills/
```

When the user wants Edge Functions on self-hosted Supabase, open or operate the
**Edge Functions Admin** at `http://127.0.0.1:9100` (Studio cannot do this).
